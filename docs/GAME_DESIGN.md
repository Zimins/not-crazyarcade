# Splash Arena — 게임 디자인 문서

물풍선 액션 아케이드(크레이지 아케이드 장르)의 메커니즘을 재현하되, 캐릭터·그래픽·명칭은
모두 오리지널로 창작한 웹 게임. 원작 IP(넥슨 캐릭터/스프라이트/사운드/명칭)는 일절 사용하지 않는다.

> 수치 출처: 원작의 공식 수치는 비공개이므로, 위키·팬 구현에서 교차 확인된 통용치를
> 기본값으로 쓰고 (코어 `core/src/constants.rs`) 플레이테스트로 조정한다.

## 1. 핵심 루프

15×13 타일 아레나에서 물풍선을 설치해 십자형 물줄기로 상대를 **물방울에 가두고**,
갇힌 상대에게 **접촉해 터뜨리면** 처치. 마지막까지 살아남은 팀(개인)이 승리.

## 2. 규칙 상세

### 이동
- 픽셀 단위 자유 이동 (타일 스냅 아님) + 4방향
- 판정·풍선 설치는 캐릭터 중심이 속한 타일 기준 → 타일 경계에 걸치는 "걸치기" 테크닉 성립
- 막힌 모서리에서 자동 미끄러짐(코너 어시스트, 임계 0.28타일)
- 충돌 박스: 반폭 0.36타일. 플레이어끼리는 충돌하지 않음

### 물풍선
- 빈 타일 1칸 점유, 동시 설치 수 = 캐릭터 스탯
- 퓨즈 **3.0초** 후 폭발 → 십자 4방향으로 물줄기 (길이 = 물줄기 스탯)
- 설치된 풍선은 통행 불가 장애물. 단 설치 순간 그 칸에 있던 플레이어는 벗어날 때까지 통과 가능 (벗어나면 다시 막힘)
- **연쇄 폭발**: 물줄기가 다른 풍선에 닿으면 즉시 동반 폭발
- 물줄기 차단: 하드 블록에서 정지, 소프트 블록은 파괴하고 그 칸에서 정지, 바닥 아이템은 파괴하고 정지하지 않음
- 물줄기 판정 **0.2초** / 시각 잔상 0.5초

### 물방울(갇힘) — 이 장르의 핵심 독창 규칙
- 물줄기에 닿으면 즉사가 아니라 물방울에 갇힘
- 갇힌 동안: 초저속 이동(0.5타일/초)만 가능, 풍선 설치 불가
- **5.0초** 내 탈출 실패 시 사망 (물방울이 점점 불투명해지는 연출)
- 같은 팀 접촉 → 구출 (횟수 무제한, 구출 직후 1초 무적)
- 적 접촉 → 즉시 터져 사망 (접촉 반경 0.7타일)
- 바늘 보유 시 액션 키로 즉시 자력 탈출

### 승패
- 상대 팀(개인전: 자신 외 전원) 전멸 시 승리
- 제한시간 3:00 초과 시 무승부 (원작에 서든데스 없음)
- 시작 연출: "GAME START!!" 배너 (내부 카운트다운 3초)

## 3. 캐릭터 (오리지널 8종, 스탯 1~10 스케일)

| | 이름 | 콘셉트 | 풍선(시작/최대) | 물줄기 | 속도 |
|---|------|--------|----------|--------|------|
| 0 | 코코 | 노란 병아리 — 밸런스/초반형 | 1/7 | 2/7 | 5/8 |
| 1 | 피코 | 하늘색 고양이 — 스피드형 | 1/6 | 1/7 | 5/9 |
| 2 | 부리 | 초록 개구리 — 물량형 | 2/9 | 1/6 | 4/7 |
| 3 | 테라 | 보라 여우 — 폭발형 | 1/7 | 2/9 | 4/8 |
| 4 | 모카 | 갈색 곰 — 대기만성형 (시작 최저, 캡 최고) | 1/9 | 1/8 | 4/8 |
| 5 | 푸딩 | 분홍 토끼 — 초반 물량형 | 2/8 | 1/6 | 5/8 |
| 6 | 치치 | 주황 다람쥐 — 질주형 (저화력) | 1/8 | 1/5 | 5/9 |
| 7 | 펭펭 | 회색 펭귄 — 초반 강세형 (캡 최저) | 1/6 | 2/6 | 6/7 |

(원작 아키타입 분포 8종 패턴 — 스피드/물량/폭발/초반/대기만성/저화력질주 — 를 따른 자체 밸런스)
속도 변환: `타일/초 = 2.0 + 0.4 × Lv`

## 4. 아이템 (소프트 블록 파괴 시 40% 드랍)

| 아이템 | 효과 | 가중치 |
|--------|------|--------|
| 물풍선+ | 동시 설치 수 +1 (캐릭터 캡까지) | 30% |
| 물약 | 물줄기 길이 +1 (캡까지) | 30% |
| 롤러 | 이동속도 +1 (캡까지) | 25% |
| 바늘 | 소지형, 갇혔을 때 사용해 탈출 (최대 3개) | 12% |
| 울트라 | 물줄기 즉시 캐릭터 최대치 | 3% |

**아이템 보급**: 남은 시간 1:59 / 1:36 / 1:14 / 0:51 / 0:29 / 0:07 총 6회, 회당 2개를
빈 칸에 랜덤 투하 (원작 아이템 비행기 차용). 블록이 모두 부서진 후반에도 파밍 거리가
유지되어 게임이 루즈해지지 않는다.

v2 후보(원작 존재 확인됨): 신발(풍선 밀기), 장갑(던지기), 다트(원격 기폭), 산소통(갇힘 연장),
디버프류(초록악마·마귀), 탈것(1회 피격 보호).

## 5. 맵 (15×13, 오리지널 레이아웃 3종)

- **숲**: 대칭 클래식 배치 — 기믹 없는 정통파
- **공장**: 중앙 십자 통로 + 하드블록 라인
- **얼음**: 트인 중앙 광장형
- 블록: 빈칸 / 소프트(파괴 가능, 아이템 드랍) / 하드(파괴 불가)
- `?` 칸은 시드 기반 50% 확률 소프트 — 판마다 지형 변화
- 스폰 4곳 코너 배치, 스폰 인접 1칸 이상 통행 보장

v2 후보: 기믹 타일(컨베이어, 하수구 연동 폭발, 내구도 블록), 빅맵, 8인.

## 6. 모드

- **솔로**: vs 봇(1~3마리, FFA/2v2), 로컬 플레이
- **온라인 멀티**: 방 목록에서 입장/생성, 방당 최대 **6인** FFA
  (방 1개 = Durable Object 1개, 결정적 시뮬 + 입력 릴레이 락스텝)

## 7. 조작

| 키 | 동작 |
|----|------|
| 방향키 / WASD | 이동 |
| Space | 물풍선 설치 |
| Space (갇힘 중) | 바늘 사용 탈출 |

## 8. 연출 노트

- 사망: 물방울 파열 → 캐릭터가 주저앉으며 사라짐 (원작은 익사 모티프 — 우리는 물에 젖어 시무룩 모티프)
- 갇힘: 비눗방울 안에서 허우적, 시간 경과에 따라 방울 불투명도 상승
- HUD: 우측 패널 — 타이머, 플레이어 슬롯(생존 상태), 내 스탯(풍선/물줄기/속도/바늘)
